      실시간 순위표

        ⚙️ 순위표 저장 공간(Firebase) 설정 방법 — 최초 1회만

        1. firebase.google.com/console 접속 → 구글 계정으로 로그인 → "프로젝트 추가"로 새 프로젝트 생성 (Analytics는 꺼도 됩니다)
        2. 왼쪽 메뉴에서 빌드 → Realtime Database 클릭 → "데이터베이스 만들기" → 테스트 모드로 시작 선택
        3. 프로젝트 설정(톱니바퀴) → "내 앱" → 웹 아이콘(</>) 클릭 → 앱 등록 (호스팅 설정은 건너뛰기)
        4. 화면에 나오는 firebaseConfig 객체 전체를 복사
        5. 이 파일에서 const firebaseConfig = { ... } 부분을 찾아 복사한 내용으로 통째로 교체하고 다시 배포
